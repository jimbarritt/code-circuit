# Agent rules

## Work on main

- Work on `main` only. Do not create branches.
- Do not open pull requests.
- Commit to `main` and push to `main`.
- Commit after each task. Start the message with the task ID.

## Prose

- Write all prose in the repo in [Software English](https://github.com/jimbarritt/software-english/blob/main/spec/SPEC.md).
